# Alisson Martins

> **Conhecer o terreno antes de escrever a primeira linha.**

A maioria olha para um problema e vê um muro.  
**Eu aprendi a ver um mapa.**

Todo problema tem mais de uma saída. Algumas estão à vista; outras só aparecem
para quem tem coragem de se virar e olhar para fora da caverna.
O que parecia limite, quase sempre, era só a sombra de algo que ninguém ainda tinha questionado.

Antes de codar, eu observo. Entendo o terreno, o ritmo, o que trava.
Depois traço os caminhos, porque nunca é um só, e construo o que leva mais longe.

*"Em meio ao caos, há também oportunidade."* (Sun Tzu)
